# مدير الحسابات الشامل (Universal Password & Account Manager)

تطبيق ويب متكامل لإدارة وتنظيم كلمات المرور والحسابات الرقمية تم إعادة كتابته كـ تطبيق **React + TypeScript + Vite**.

## المميزات الرئيسية
- **التشفير القوي:** تشفير كلمات المرور المخزنة باستخدام معيار AES المتقدم عبر Web Crypto API.
- **إدارة الحسابات:** تصنيف الحسابات إلى (التطبيقات والمنصات، البريد الإلكتروني، المواقع الإلكترونية) مع دعم الإضافة، التعديل، والحذف.
- **كشف ونسخ كلمات المرور:** إمكانية إظهار/إخفاء كلمات المرور ونسخها بنقرة واحدة.
- **نظام المصادقة والجلسات:** تسجيل الدخول والتسجيل المباشر مع انتهاء الجلسة التلقائي بعد 15 دقيقة من عدم النشاط.
- **لوحة تحكم المشرف:** إمكانية متابعة المستخدمين وإحصائيات الحسابات لحساب المشرف (`admin` / `morad`).
- **مدونة الأمن السيبراني:** مقالات شاملة ومتخصصة في أمان كلمات المرور والمصادقة الثنائية وحماية البريد وحسابات التواصل.
- **إعدادات المستخدم:** تغيير اسم المستخدم، تحديث كلمة المرور الرئيسية، وخيار حذف الحساب نهائياً مع كافة البيانات.
- **المظهر الداكن والفاتح:** دعم تبديل المظهر (Dark / Light Theme) مع الحفظ التلقائي في التخزين المحلي.
- **التوافق التام:** متوافق مع كافة أحجام الشاشات والأجهزة، ويدعم اللغة العربية وتوجيه RTL بالكامل.

## التشغيل والتطوير
```bash
npm install
npm run dev
```
يعمل خادم التطوير على المنفذ `3000`.
